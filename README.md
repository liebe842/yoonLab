# yoonLab 작품 전시관

직접 만든 코딩 작품을 책장에 꽂아 보여 주는 한 장짜리 웹페이지입니다.
책을 누르면 표지가 보이고, 표지의 "열어 보기"를 누르면 작품이 새 창에서 열립니다.

- 페이지 주소: https://liebe842.github.io/yoonLab/

## 새 작품 추가하기

고칠 파일은 **`works.js` 하나뿐**입니다.

### 방법 1. Claude에게 말하기 (가장 쉬움)

이 폴더에서 Claude를 열고 이렇게 말합니다.

> 작품 추가해 줘. 제목은 ○○, 설명은 ○○, 주소는 https://○○

Claude가 목록에 넣고, 표지 사진을 찍고, 인터넷에 올리는 것까지 합니다.

### 방법 2. 깃허브 사이트에서 직접 고치기

1. https://github.com/liebe842/yoonLab/blob/main/works.js 를 엽니다.
2. 오른쪽 위 연필 모양(Edit)을 누릅니다.
3. 맨 위 설명에 있는 **견본 묶음**(`{` 부터 `},` 까지)을 복사해서, `const WORKS = [` 아래 작품들 사이의 넣고 싶은 자리에 붙입니다. 다른 작품의 `},` 바로 다음 줄에 붙이면 됩니다.
4. 큰따옴표 안의 글자만 바꿉니다.
   - `title`: 책등과 표지에 보일 제목
   - `description`: 표지에 보일 한 줄 설명
   - `url`: 작품 주소 (`https://` 로 시작)
   - `shelf`: 꽂을 칸 이름. 지금은 `"웹앱"` 과 `"수업·연수 자료"` 두 칸이 있습니다. 새 이름을 쓰면 새 칸이 생깁니다. 이 줄을 지우면 "웹앱" 칸에 꽂힙니다.
   - `image`: 표지 사진. 사진이 없으면 이 줄을 지우세요. 제목 글씨로 꾸민 표지가 됩니다.
5. 오른쪽 위 초록 단추 **Commit changes** 를 두 번 누릅니다.
6. 몇 분 뒤 페이지를 새로고침하면 책이 한 권 늘어나 있습니다. (길면 10분쯤 걸릴 수 있습니다.)

### 책을 빼거나 순서를 바꾸려면

- 빼기: 그 작품의 묶음(`{` 부터 `},` 까지)을 통째로 지웁니다.
- 순서: 묶음을 통째로 잘라 원하는 자리에 붙입니다. 같은 칸 안에서는 목록에 적힌 순서대로 왼쪽부터 꽂힙니다.
- 칸 순서: 칸은 목록에 처음 나온 순서대로 위에서부터 놓입니다. 같은 칸의 작품은 목록에서 한데 모아 두면 헷갈리지 않습니다.

### 페이지가 이상하게 보이면

"작품 목록 파일(works.js)을 읽지 못했어요"라는 글이 보이면, 마지막으로 고친 묶음에서
쉼표(`,`)나 따옴표(`"`)가 빠진 것입니다. 묶음 끝의 `},` 와 각 줄 끝의 `,` 를 확인해 주세요.

책이 안 보이는 작품이 있으면 그 묶음의 `title` 이 비었거나 `url` 이 `https://` 로 시작하는 온전한 주소가 아닌 것입니다.

## 파일 설명

| 파일 | 역할 |
|---|---|
| `works.js` | 작품 목록. 고칠 곳은 여기 하나 |
| `index.html` | 페이지 본체 |
| `style.css` | 책장, 책, 표지의 모양 |
| `gallery.js` | 목록을 읽어 책을 꽂고, 누르면 표지를 보여 주는 부분 |
| `shots/` | 표지에 들어가는 작품 화면 사진 |

## 표지 사진을 직접 찍을 때 주의

작품에 **로그인한 상태로 찍지 마세요.** 선생님 이름이나 학급 자료가 사진에 찍혀 누구나 볼 수 있게 됩니다.
로그인하지 않은 첫 화면만 찍어서 `shots/` 폴더에 넣고, `image: "shots/파일이름.jpg"` 로 적습니다.
